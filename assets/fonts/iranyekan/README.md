# فونت ایران یکان

برای استفاده از فونت ایران یکان در گزارش‌های PDF برنامه خودرویار، لطفاً فایل‌های فونت را در این پوشه قرار دهید.

## فایل‌های مورد نیاز

```
assets/fonts/iranyekan/
├── IRANYekanX-Regular.ttf
├── IRANYekanX-Medium.ttf
└── IRANYekanX-Bold.ttf
```

## نکات مهم

1. **ایران یکان یک فونت تجاری است**
   - لطفاً آن را از منابع قانونی تهیه نمایید
   - بدون مجوز رسمی، استفاده از این فونت غیرقانونی است

2. **نحوه استفاده**
   - فایل‌ها را با نام‌های دقیق فوق در این پوشه قرار دهید
   - برنامه به صورت خودکار آن‌ها را شناسایی و در گزارش‌ها استفاده می‌کند
   - بدون این فایل‌ها، برنامه از فونت پیش‌فرض سیستم (Vazirmatn) استفاده خواهد کرد

3. **محل قرارگیری**
   - فایل‌ها باید در مسیر `assets/fonts/iranyekan/` قرار گیرند
   - نام فایل‌ها باید دقیقاً مطابق لیست فوق باشد

## منابع قانونی برای تهیه ایران یکان

- سایت رسمی ایران یکان: [https://iranyekan.com](https://iranyekan.com)
- فروشگاه‌های معتبر فونت فارسی
- پلتفرم‌های رسمی فروش فونت

## فونت‌های جایگزین رایگان

در صورت عدم دسترسی به ایران یکان، برنامه از فونت‌های زیر به عنوان جایگزین استفاده می‌کند:

- **Vazirmatn** - فونت اوپن سورس کامل فارسی
- **Sahel** - فونت سبک و خوانا
- **Samim** - فونت مدرن فارسی
- **Dana** - فونت همه‌کاره فارسی

این فونت‌ها در اغلب سیستم‌ها به صورت پیش‌فرض نصب هستند یا می‌توانند به صورت رایگان دانلود شوند.

## مجلز و شرایط استفاده

- ایران یکان تحت مجوز تجاری عرضه می‌شود
- استفاده بدون مجوز غیرقانونی است
- برای اطلاعات بیشتر، به سایت رسمی مراجعه نمایید

## نکات فنی

- فونت‌ها باید در قالب TTF باشند
- اندازه فایل‌ها باید معقول باشد (حداکثر 5MB برای هر فایل)
- فونت‌ها به صورت Embedded در PDF قرار می‌گیرند
- از هیچ سایت غیر رسمی برای دانلود استفاده نکنید

## IranYekan Font

To use IranYekan font in KhodroYar PDF reports, please place the font files in this directory.

### Required Files

```
assets/fonts/iranyekan/
├── IRANYekanX-Regular.ttf
├── IRANYekanX-Medium.ttf
└── IRANYekanX-Bold.ttf
```

### Important Notes

1. **IranYekan is a commercial font**
   - Please obtain it from legal sources only
   - Using without license is illegal

2. **How to Use**
   - Place files with exact names above in this directory
   - The app will automatically detect and use them
   - Without these files, the app falls back to Vazirmatn

3. **Legal Sources**
   - Official website: [https://iranyekan.com](https://iranyekan.com)
   - Licensed font marketplaces
